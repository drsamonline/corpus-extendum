How a book gets on this shelf

Four steps, run as a batch job. No book is added by hand, and no book is added without passing the copyright gate.

01 Fetch

Pull from the source

Text and artwork come from Standard Ebooks where an edition exists, from the Gutenberg mirror otherwise, and from archive.org for a scan that exists nowhere else.

02 Verify

Pass the copyright gate

Author's death year + 60 for India, publication year for the US. Both must pass. The basis is written into the record so any reader can audit it.

03 Build

Make the reading files

A PDF is typeset for the screen, the EPUB is kept, text is extracted for in-book search, plates are downscaled, and a hash is stored to catch duplicates.

04 Shelve

File it in a vault

Files are committed to the open vault repo, its index.txt is rewritten, and this catalogue picks the book up on the next scan.

Duplicates are refused twice, and never merged late. Once before fetching, when the source reference is already in the register — and again at ingest, where the hash of the normalised text decides what this actually is: a new book, another format of one already on the shelf, or a different edition. A book is added once; its extra formats join the same card. Nothing is ever added on a fuzzy match.
